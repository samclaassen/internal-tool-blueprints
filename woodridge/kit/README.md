# AEO Explainer Video kit

A portable copy of the daily YouTube automation (avatar hook → narrated content → outro, plus a Short),
adapted for brands with no product footage: visuals are curated, openly licensed images and clips
(Openverse, Wikimedia Commons, optional Pexels/Pixabay) or the brand's own media, all credited.

How to use in a new project:
1. Upload this zip as a skill in the new space (or upload the folder's files to a new skill). SKILL.md is the skill.
2. Copy brand.example.json to brand.json and fill in every TODO (brand, domain, host, colours, HeyGen ids,
   YouTube channel, media repo, music).
3. Connect HeyGen and YouTube as custom API connections in that space.
4. Do one supervised first video with the skill, then paste AUTOMATION.md (placeholders filled) into a daily scheduled task.

Nothing in here points at Personal Software Factory: no channel ids, avatar/voice ids, repos or domains.
